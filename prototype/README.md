# LexisGraph 详细交互原型

直接打开 `index.html`。所有资源在本目录内，不需要启动后端或安装依赖。建议用 1440px 以上窗口查看三栏工作台；窄屏会自动改为纵向布局。

## 可评审的流程

1. **任务入口**：工作台首页提供两个快捷入口；“审查记录”和“模板核验记录”页顶部也分别提供新建按钮。两个新建流程有独立准备页，不占用侧栏菜单。风险审查可上传文件或粘贴正文，设置立场、尺度、分类、清单、背景与重点要求；模板核验选择已发布版本并上传 DOCX。
2. **合同工作台**：双栏布局。左侧只读合同正文；右侧融合审查概览与问题导航。点击问题行会在该行下方展开原文证据、修订差异、判断依据和处理按钮，同时定位正文；再次点击收起。可切换修订标记、当前稿、原始稿、双栏对照、要求核验及处理记录。工作台不提供正文或建议编辑入口；完成审核后，右上角“导出”才会启用，并统一提供当前稿、修订稿、意见书和审核记录。
3. **合同起草**：填写合同类型、双方名称和交易需求，生成示例草稿，在纸张视图编辑或预览，保存、导出或送入审查。
4. **工作记录**：搜索、按状态筛选、继续复核、查看模板核验报告及导出示例文件。
5. **标准与资料**：查看合同模板、审查清单、业务分类；查看模板字段规则、发布版本和核验路径。

## 原型边界

这是设计评审用的前端原型。数据为示例数据，状态只保留在当前页面；上传不会读取合同内容，生成、核验和审查不会调用模型或后端。导出按钮下载标有“原型示例”的 TXT 文件，正式 Word、CSV、JSON 导出仍以现有系统为准。

界面刻意不提供综合风险分数。风险通过具体问题、等级、证据和处理状态呈现。
