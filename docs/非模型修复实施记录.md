## 数据迁移、保留和恢复

新增两个分类唯一索引和 review_events 表，启动时幂等创建，不重写既有合同/运行数据。已有重复分类会阻止唯一索引建立，需要先备份并人工合并。原目录布局不变；使用 LEXIS_DATA_DIR 时数据库与 sources 跟随该目录，只配置 LEXIS_DB_PATH 时 sources 跟随数据库父目录。改变目录前先停服并复制数据。

归档保留全部历史和源文件；当前不自动彻底删除合同。启动对账与 verify 报告缺失、哈希不符及未引用文件，不自动删除。旧源文件没有哈希时仅核对存在性。统一数据根目录的具体用法、备份、在新空目录恢复和回滚步骤见 README。
