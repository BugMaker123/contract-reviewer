# 工作台交互与功能边界

主流程：阅读合同 → 修改正文或记录意见处理 → 按需重新审查。重新审查创建新版本，不是其他操作的前置步骤。

| 功能 | 内容归属 | 可用条件 |
| --- | --- | --- |
| 编辑、保存、下载合同 | 当前文档 | 有正文即可下载；编辑限制历史只读及审查进行中 |
| 不采纳、待复核、备注 | 选定审查版本的人工处理记录 | 不依赖正文与审查快照一致；历史版本只读 |
| 查看、导出审查资料 | 明确标注的某次审查快照及处理记录 | 审查已完成；后续编辑不阻止查看旧资料 |
| 采纳建议 | 将该次审查的建议应用到对应正文 | 必须确保建议与正文版本一致，防止误替换 |
| 重新审查 | 当前合同及审查设置 | 显式触发并创建新快照 |
| 完成复核 | 当前审查流程 | 当前正文已审查并完成人工处理 |

顶部只保留下拉导航、审查设置、意见书与审查主操作；本页不提供新建审查入口，导航菜单仅保留首页及记录。审查立场采用下拉框。文档区只保留标题、保存状态、合同文档、编辑及保存。移除原件、合同正文、已采纳修订稿之间的重复标签；采纳效果直接在同一份格式化文档中呈现。更多操作分为当前合同下载、审查历史、审查资料导出、复核流程。移除重复风险横条，评分集中放在左侧。

下载当前合同与导出审查版本修订稿是独立入口；后者明确说明不包含后续人工编辑。旧意见书显示对应审查版本及后续变更提示。审查立场、条件、模型只影响下一次审查，不阻止当前文档阅读、编辑或人工状态记录。

人工处理状态及备注不改变文档预览地址；只有文档内容或实际采纳项变化才刷新预览。


文档对照：打开工作台默认单栏显示原始文档。显式点击开始审查或重新审查后，文档区切换为左右双栏：左侧固定本次送审前的正文与文档版本，只读；右侧在审查期间显示进度，完成后呈现全部建议稿。阅读区优先：审查概览与审查意见两侧默认展开，侧栏与文档交界处中部的三角把手独立控制收起与展开；移除顶部审查概览按钮。收起后保留 36px 窄边栏及展开箭头。面板展开会重新分配文档宽度并自适应缩放，禁止覆盖文档；关闭后文档自动扩宽，意见面板不会因 Escape 或打开概览而隐藏。法律依据与处理建议折叠展示，原文证据限制高度，定位高亮采用浅蓝色侧边提示。右侧未自动采纳任何建议；若多项建议存在文本冲突，安全合入可匹配项，其余保留在意见栏并提示冲突数。右侧人工编辑保存不改变左侧冻结版本。刷新或重新打开工作台恢复单栏。Word 两侧使用同一渲染方式保留排版，PDF/TXT 原文继续使用其对应预览，修订建议以 Word 版式呈现。

文档工具栏压缩为单行，标题与合同类型在左，编辑、保存及更多操作在右；移除重复的对照说明和常驻保存状态。保存失败仍显示错误，保存期间由保存按钮反馈。

当前阶段将“更多操作”完整注释保留，界面不显示该入口。文档工具栏直接提供编辑、保存、导出及完成复核。导出对应当前显示的文档：对照时导出右侧建议稿，编辑后导出当前编辑稿。缩放工具使用适宽、缩小、百分比、放大按钮组，替代原生下拉框。

文档面板工具栏统一为单行：左侧文档角色及只读/建议稿/编辑稿标签，右侧缩放和下载；文件名放在标题悬停提示中，不重复占行。原文定位成功等常规状态保留无障碍播报，不占用工具栏高度；错误与冲突提示仍可见。编辑时才出现保存与取消操作。

Word 对照阅读采用单一可见滚动条：隐藏左侧滚动条，两侧滚轮及右侧拖动均通过段落映射同步，长度不同处使用滚动比例兜底。后端按行计算增删改区间和双向位置映射，左侧用淡灰蓝标出原文差异，右侧用浅绿背景及绿色边线强调修订差异；标记不修改 Word 正文内容，保存后重新计算。

编辑统一草稿：Word 正文输入实时同步到当前草稿并重新计算差异；取消编辑恢复对应文档版本及差异。条款弹窗读取当前草稿的最新文本，仅替换目标条款，其余未保存修改一并保留；同一目标已被改动而无法唯一匹配时拒绝覆盖。顶部保存提交正文草稿，不仅保存任务信息。保存期间暂时锁定编辑，避免后返回的旧内容覆盖新输入。

侧栏切换不会重新载入文档，只重新分配可用宽度并切回适宽缩放；按文档实际页宽和内容溢出宽度计算比例，长连续字符可换行。两侧独立滚动自身内容，不覆盖中央文档。

侧栏展开宽度：概览 320px、意见 360px；较窄窗口分别使用 280px、340px。意见处理按钮使用单行紧凑布局，追问入口不另起一行。

审查重点自动标记：每次开始及完成审查均展开两侧栏；审查完成后同时标记文本差异与可定位风险证据，后者使用红色风险高亮，即使没有替换建议也会标记。首次自动定位首个重点，后续编辑不重复跳转。文档尚未完成渲染时暂存标记，渲染结束后补绘；侧栏把手采用可旋转的 SVG 折叠图标。

同一原文条款的多个风险合并为一张卡片，逐项说明问题，共用处理状态与统一改写。审查后通过模型生成覆盖各问题的完整条款，自动应用到右侧建议稿并以红色高亮差异，采纳状态仍由用户确认。模型不可用时只应用可验证且无冲突的已有建议，明确提示缺失或部分改写，不把原文冒充成已改写内容。历史审查结果保持原样，重新审查后采用新分组。

双栏文档默认统一使用 80% 缩放；收起左侧审查概览后两侧切换为 100%，重新展开恢复 80%。文档重新加载也遵循左侧展开状态，仍保留手动适宽与加减缩放。

刷新已审查任务时，从已保存审查版本恢复双栏对照及原始快照；右侧恢复全部建议稿，如有后续人工保存则恢复当前编辑稿。该状态不依赖 localStorage，清理浏览器缓存也不丢失服务端审查结果。

缩放规则更新：任一侧栏收起时，双栏文档统一 100%；两侧均展开时为 80%。缩放操作合并为紧凑菜单，提供适应宽度及 50%、80%、100%、125%、150%、200%，移除独立适宽与加减按钮。
