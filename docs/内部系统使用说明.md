# 内部合同工作系统使用说明

## 页面入口

- 开始：准备合同和审查条件。
- 审查记录：打开长期保存的任务，筛选、归档和恢复。
- 审查清单：维护企业检查要求，保存草稿或发布版本。
- 合同起草：从交易背景确认信息、生成大纲和正文。
- 起草记录：继续已有草稿，查看过去保存的版本。

系统保留原有蓝白灰风格与三栏工作台。社区、付费升级、开票、推广与小程序不在功能范围内。

## 新建审查

1. 选择审查方式，上传 DOCX、文字型 PDF 或 TXT，也可粘贴正文。
2. 核对提取内容，填写名称、类型、我方立场和审查尺度。
3. 清单审查必须选择已发布清单；对比审查必须提供参考合同。
4. 按需要填写交易背景、重点要求。深度审查可添加最多五份、合计五万字的参考资料。
5. 进入工作台核对，再点击开始审查。

文件最大 10 MB、正文最多二十万字。扫描 PDF 需要先做 OCR。旧版 DOC 请另存为 DOCX。

快速审查使用基础规则，不调用模型做语义判断。深度审查使用已配置模型，模型不可用时明确显示规则回退及覆盖范围。清单中的文字规则可直接匹配，语义条目需要模型；无法确定时显示待确认。对比模式始终能定位文本变更，可用模型进一步分析变更影响，否则保留待人工评估。

## 工作台处理

- 左栏显示本次审查概览，清单和对比模式使用对应的检查面板。
- 中栏保留审查原文与已采纳修订稿；对比模式可切换差异对照。
- 右栏按条目展示风险、依据、建议、差异或原文证据。
- 可采纳和撤销修订，记录不采纳、待复核状态与人工备注；采纳不能唯一匹配原文时会阻止替换。
- 可编辑整个正文或某条款；修改后需要重新审查，旧审查快照和处理状态继续保留。
- 单条追问在该意见下展开，需可用模型；回答保存在该审查版本，不自动覆盖合同。
- 有审查记录的任务会自动保存，保存状态在顶栏显示。保存发生冲突时保留当前页面输入并提示重新打开，不覆盖其他页面的修改。
- 每次重新审查创建独立版本。使用“以已采纳稿再审查”可以核验修改后的文本；普通重新审查使用当前审查正文。历史版本可查看和导出，编辑需返回当前任务。
- 所有意见已处理后，可点击完成复核；待处理或待复核条目尚未处理完时不会标记完成。

## 企业审查清单

清单由名称、适用范围和检查项组成。每项填写标题、具体要求、核验方式与风险等级。

核验方式包含语义核验、必须包含全部文字、至少包含一项文字、不得包含指定文字。文字匹配不等同于法律效力判断；需要理解条款意义时选择语义核验。

文件导入先按行提取清单草稿，请合并标题、核对具体要求后发布。修改已有清单形成新版本，已创建任务继续使用原来的快照，不随清单修改而改变结果。

## Word 导出

工作台可以选择：当前修订稿、当前修订稿含修订痕迹、全部建议稿、全部意见书、仅已采纳意见书。

全部建议稿会尝试应用所有有效修订建议，其内容可能不同于当前预览。有重叠或匹配冲突的建议会提示人工处理，不静默跳过。

上传的原 DOCX 正文与本次审查原文一致时，尽量保留原有段落、表格、页边距、页眉页脚及未修改的文字格式。对于粘贴、PDF、TXT，以及原文已重新编辑的情况，导出采用统一 Word 版式，并给出提示。

含修订痕迹的版本使用 Word 原生插入和删除标记；人工备注以 Word 批注形式锚定到可匹配的段落。请核对复杂表格、图片、域和现有修订标记等特殊内容的交付效果。

## 合同起草

1. 描述起草背景，可加入参考模板和参考资料。
2. 分析并确认交易信息；也可以手动填写。不确定的金额、主体和期限保留待确认。
3. 生成或填写条款大纲，核对后生成正文。
4. 编辑正文。定向改写先选中原文、描述要求，再核对建议，确认后保存替换。
5. 保存、导出 Word 或送入审查。每次保存和生成保留历史草稿版本。

模型未配置或生成失败时，原输入、大纲和已有正文保留。生成模型的输出质量和企业审查规则的业务正确性需结合实际合同复核。

## 保存与运行范围

当前版本是单个内部实例，默认只监听本机 `127.0.0.1:8000`。尚未接入组织账号、多人权限或审批流程。

数据库位于 `data/lexis.db`，上传的原始文件位于 `data/sources/`；备份时应同时备份两者。浏览器会话只保存临时表单，长期记录存放在服务端。归档可恢复，不会删除案件。

服务重启后，尚未完成的任务标记为已中断；输入快照及此前完成的版本保留，可重新发起。

原件预览：上传 DOCX/PDF 后，工作台默认显示本地保存的上传原件。DOCX 使用本地 docx-preview 0.3.6 与 JSZip 3.10.1 渲染，支持缩放和下载原件；不会把合同上传至在线转换服务。浏览器排版不保证与 Word 的分页、浮动对象完全一致。审查文本负责风险高亮和定位，已采纳修订稿单独展示。正文编辑与采纳建议不会修改上传原件。Markdown 仅适合内容整理，不能保留 Word 原始排版。

原件定位更新：点击右侧审查意见时，Word 原件视图保留排版，在匹配段落上添加高亮并滚动定位；重复匹配或无法匹配会显示提示，不自动切换到纯文本。PDF 原件暂不支持段落高亮，可手动切换审查文本定位。
