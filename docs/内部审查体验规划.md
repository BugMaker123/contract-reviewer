# 内部合同审查：主页与工作台

2026-10-14 更新：已登录参考网站的实际功能对照及新版范围见 [参考网站功能对照与实施方案](参考网站功能对照与实施方案.md)。以下内容继续作为上一轮已实现改动的记录，后续实施顺序以新版方案为准。社区、商业升级、开票、推广与小程序均不纳入内部系统。

## 使用路径

导入实际合同 → 核对正文、名称、类型与我方立场 → 发起审查 → 定位风险 → 逐项采纳或撤销 → 核对修订稿 → 导出修订稿与审查意见书。

保持现有蓝白灰色系、细边框、圆角卡片、商务正文排版与工作台三栏结构。主页承担任务准备，工作台承担审查与修订；不增加宣传区、技术架构展示或虚构业务统计。

## 主页（本次已实现）

| 功能 | 使用目的与行为 |
| --- | --- |
| 上传合同 | 默认入口。真实提取 DOCX、文字型 PDF、TXT，支持拖拽；不支持的格式或扫描 PDF 明确报错，绝不替换为示例。最大 10 MB、20 万字。 |
| 粘贴正文 | 支持完整合同或单项条款，显示字数。 |
| 合同信息 | 编辑名称、类型，确认甲乙方立场。 |
| 正文核对 | 上传后可展开查看与修正提取的内容，进入工作台后再发起审查。 |
| 继续工作 | 显示当前会话最近合同、是否已有结果、采纳数量，可直接恢复。 |
| 示例合同 | 作为熟悉流程的辅助入口，不默认选中。 |
| 配置与清单 | 保留必要的配置和检查范围说明，去掉宣传性技术介绍。 |

## 工作台（本次已实现）

- **左栏保留**评分、财税检查与审查进度，补充实际结果来源及评分基准说明。
- **中栏保留**正文阅卷排版与风险批注。原文始终保留；修订稿只包含已采纳项。允许编辑正文、名称和类型，并提供 TXT 修订稿下载。
- **右栏保留**风险卡片、依据、谈判建议与修改对照。增加搜索、风险等级与处理状态筛选，按严重程度排序；支持采纳与撤销。遇到原文无法匹配、重复匹配或修改冲突时提示人工核对，不盲目替换。
- **审查过程**使用服务端真实节点事件，不再模拟进度。支持取消；失败和连接中断明确显示，未完成时不生成可导出的结果。
- **版本一致性**正文、立场、名称或类型与审查快照不一致时显示结果过期，并暂停采纳和意见书导出。恢复原审查信息可以继续使用对应结果。
- **恢复与交付**当前浏览器会话自动保存合同、结果和采纳状态；报告显示实际审查时间、来源及处理状态。打印时隐藏界面并解除报告滚动容器的分页限制。
- **内部网络**Vue、样式均在本地加载，正常打开页面不依赖外部 CDN。

## 边界与下一阶段

本次工作是单人、当前浏览器会话内的审查闭环。会话存储不是长期档案库，不等于多人协作或审批记录。PDF 扫描件尚不支持 OCR；修订稿导出为 TXT，不保留原 Word 排版。

下一阶段建议按真实内部需求依次开展：

1. **长期案件与版本存储**：合同编号、负责人、草稿/审查中/待复核/已完成状态、审查快照与修订版本；主页随后展示真实待办与最近案件。
2. **内部审查标准**：按业务合同类型配置检查项、默认立场、企业条款底线与允许例外，并给规则加版本。
3. **交付能力**：保留版式的 DOCX 修订与意见书、扫描件 OCR，并支持人工校对提取结果。
4. **多人复核**：落实使用者身份后，再增加指派、备注、审批与审计记录。

不提前做没有真实数据的统计卡片、团队活动或审批入口。现有规则引擎与模型输出的法律判断质量仍需要单独进行业务验收；本次没有将界面优化视为审查规则质量认证。
