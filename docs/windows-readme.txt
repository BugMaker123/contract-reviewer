LexisGraph Windows 免安装版

1. 将压缩包完整解压到一个文件夹，不要直接在压缩包里运行。
2. 双击 LexisGraph.exe，启动后自动打开浏览器。
3. 保留启动窗口；使用结束后关闭启动窗口，服务会退出。
4. 第一次使用，请在页面的“模型配置”中填写模型地址、名称和 API Key。
   AI 功能需要联网；本包不包含任何 API Key。
5. 合同、模板和记录保存在 %LOCALAPPDATA%\LexisGraph。
   启动窗口可打开数据目录；备份时请先退出程序，再复制整个数据目录。
6. 启动失败时，请查看数据目录中的 application.log。

本包不包含开发环境中的合同、数据库或模型密钥。
适用：Windows 10/11 x64。无需安装 Python 或 Node.js。
这是未做代码签名的测试版本，首次运行可能出现 Windows 发布者提示。
