# 本地知识库、对话与合同审查

本次仅修改 Python 与 Vue。沿用 FastAPI、Vue、SQLite 和现有文件解析，无需新增数据库服务。

## 使用

1. 在“知识库与图谱”上传 DOCX、文字型 PDF 或 TXT。原件由已有文件入口保存；提取文本分段并建立本地关键词同现索引。
2. 需要实体语义关系时，先在“模型配置”中配置模型，再点击对应资料的“构建语义图谱”。每8个片段发起一次模型请求，较大资料会消耗多次调用。
3. 在“知识库对话”输入问题。输入框中的“添加参考资料”选择本轮资料，也可以直接上传；没有选择资料时为普通对话。无可用模型时仅提供原文检索摘录，不伪装成语义回答。
4. 通过“用于合同审查”进入新建审查，展开“知识库与对话辅助审查”，选择资料和具体消息，并确认对话内容。也可在新建审查时直接选择知识库资料。
5. 检索原文和选定对话作为审查参考资料进入既有图流程。工作台概览和 Word 意见书提供证据快照；不会把助手回答自动升级为硬性审核规则。

修改后需要重新启动 Python 服务，并执行 `npm --prefix frontend run build`。仅重建 Vue 不会让旧 Python 进程加载新接口。

## 实现范围

- 文件解析沿用 `document_import` / `document_parse`，不是用图谱替代文件读取。切片保留提取文本的字符范围与起始行号；这里的行号不是 PDF 页码或 Word 页码。扫描图片及 OCR 未接入。
- 本地索引包含分词词频及明确标注的“同片段出现”边。同现不能解释为法律关系。
- 模型索引提取实体及关系，并要求实体名称和引用能逐字匹配来源片段。校验确保出处存在，不等于已经证明模型对关系的理解正确；仍可展开原文人工核对。
- 检索使用词频/逆文档频率相关性评分，以及最多两跳的实体关系扩展，可在所选文档间连接同名实体。不使用远程向量库。
- 这是面向本地合同资料的轻量 GraphRAG 实现；未接入向量嵌入、同义实体归并、社区发现和全局社区摘要，也不是 Microsoft GraphRAG 完整管线。大规模资料集需进一步增加增量索引、实体消歧和检索评估。
- 每次最多选择30份资料；审查最多取20个检索片段，对话最多取12个。未命中不能断言资料不存在；未对整个知识库逐条完成合规核验。
- 多轮对话最多50轮；生成时携带最近12条消息。更早消息可在历史中查看，但不作为无限上下文发送。
- 新请求复用现有 `model_json` 脱敏及重试机制；模型配置仅随请求使用，不写入资料、会话或任务记录。模型接口失败或引用校验失败，本轮消息不入库；图谱构建失败保留原索引。

## 数据与版本

`objects` 表新增 `knowledge_document` 和 `knowledge_session` 两种对象，无破坏性表迁移。资料记录存储来源ID、文本校验值、分段、实体及关系；会话存储消息与引用快照。

任务保存本次检索证据、资料索引版本、文档校验值、选定消息及确认状态；创建审查版本时进一步固定输入快照。删除知识库条目不删除原件、历史会话与旧审查快照。任务正文、重点或来源选择改变时重新检索；其他条件保存沿用已有证据，避免后台索引变化静默改变旧任务依据。

## 验证

`python -m pytest tests/test_knowledge.py -q` 覆盖原文偏移、跨文档关系扩展、伪造实体关系引用、模型回答引用、失败回滚、会话版本冲突与重开、审查确认门槛、证据快照不变性、资料范围隔离、检索证据传入审查图，以及浏览器上传、多轮问答、历史恢复和带入审核。

模型返回由测试替身验证，未调用付费模型；真实模型的生成效果需使用实际资料与配置另行评估。测试使用隔离数据库与源文件目录。
